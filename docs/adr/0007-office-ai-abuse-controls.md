# ADR-0007: 학교 챗봇을 범위 검사·근거 검증·원자적 사용량 예약으로 제한한다

- 상태: Accepted (구현 및 테스트 완료, 운영 배포는 별도)
- 날짜: 2026-11-13
- 관련: ADR-0005, ADR-0006, `docs/office-ai-guardrails.md`

## 문제

공지 키워드와 유효한 인용 번호를 붙여도 일반 작업을 요청할 수 있었다. 기존 인용 검사는
실제 근거 일치를 판정하지 않았고, DB 문의 개수를 센 뒤 외부 호출하는 일일 제한은 동시 요청을
예약하지 않았다. 별개의 문의·직접 상담 요청으로 여러 상담방을 열 수도 있었다.

## 결정

1. `OVLO_LLM_ANSWER_MODEL=claude-sonnet-5-5`를 답변·범위 검사·독립 근거 검사에 사용한다.
   기존 `OVLO_LLM_MODEL`은 공지·상담 메시지·중고거래 번역용으로 보존한다.
2. 권한 확인 후 Redis Lua로 회원별 동시 요청, 학교·전체 호출 횟수와 가중 토큰 예산을
   **범위 검사 호출 전** 예약한다. SDK 재시도와 챗봇의 공급자 자동 폴백은 사용하지 않는다.
3. 범위 검사 결과는 `ALLOW`/`DENY`만 수용한다. 일반 코딩·과제 대행·창작·임의 번역·지침 변경·정보 탈취와
   학교 질문을 섞은 요청은 `OUT_OF_SCOPE`로 저장한다. 모델의 거절 문구를 그대로 노출하지 않는다.
4. 기존 인용/URL 검사 뒤 별도 LLM 호출로 모든 사실·날짜·조건이 현재 인용 자료에 근거하는지 확인한다.
   이 검증의 부정 판정은 `NO_GROUNDS`, 장애·비정상 형식·잘린 응답은 503으로 처리한다.
   검증되지 않은 답변은 저장하거나 학생에게 내보내지 않는다. LLM에 도구·외부 URL 조회 권한은 없다.
5. `OUT_OF_SCOPE`의 상담 전환은 UI뿐 아니라 서버 서비스와 도메인에서도 거절한다.
   상담 생성은 같은 트랜잭션 안에서 학생 행을 잠그고, 학교별 미종료 상담 1개와 회원별 최근 24시간 3개를 검사한다.
   같은 문의의 재시도는 기존 상담을 반환한다. 직접 상담도 동일한 생성 제한을 적용한다.
6. 새 결과값은 기존 VARCHAR(20)에 저장한다. 기존 Flyway 파일은 수정하지 않는다.

## 절충과 한계

- 정상 답변은 최대 3회(분류·생성·검증) 호출한다. 비용·지연이 늘지만 Sonnet으로 비용을 낮추고
  사용량 제한에 세 호출 모두 포함한다. 후보가 없는 질문도 범위 분류에는 비용이 발생한다.
- 같은 모델을 이용하는 분류·검증은 확률적 방어다. 성공한 공격이 절대로 없다는 보장은 하지 않는다.
  인증·학교 격리·쿼터·도구 미제공이 모델 판단과 독립적인 경계다. 프롬프트에 비밀을 넣지 않는다.
- 토큰 예산은 공급자 청구 금액 보장이 아니다. 챗봇의 전역 예산이며 별도 번역 작업을 포함하지 않는다.
- Redis 장애 시 호출을 허용하지 않는다. Redis 재시작/복구로 카운터가 사라지는 경우는 영속성 운영으로 관리해야 한다.
- 프로세스 사망·사용량 불명확 오류는 예약량을 환불하지 않는다. 동시 작업 임대는 600초 후 만료한다.
- 승인 자료 본문 최대 3,000자·총 30,000 UTF-8 바이트와 최근 최대 6턴·총 15,000바이트로 문맥을 제한한다.
  문단별 검색과 금액 단위 학교별 청구는 이번 결정에 포함하지 않는다.
- 롤백 시 OUT_OF_SCOPE를 해석하지 못하는 이전 바이너리로 단순 전환하면 안 된다.
  이 결과값의 읽기를 지원하는 호환 수정 버전으로 롤백한다. 저장된 거절을 NO_GROUNDS로 바꿔 상담을 허용하지 않는다.

## 검증

- 실제 Redis에서 마지막 일일 슬롯의 20개 동시 요청은 정확히 1개만 통과한다.
- 실제 PostgreSQL에서 서로 다른 문의의 동시 상담 생성은 정확히 1개만 저장한다.
- 검사 장애, 가짜 인용, 원문과 다른 사실, 재조회 후 이관 차단, 학교 변경을 통한 동시 제한 우회를 회귀 테스트한다.
- 실제 BizRouter/Sonnet 검증 결과: `docs/validation/office-ai-guardrails-20261113.json`.
  정상·후속·근거 부족·민감한 학생 지원·직접/간접 프롬프트 공격을 포함한다.
