# ADR-0008: 인증 응답의 세션 귀속과 번역 누적 호출 제한

- 상태: Accepted
- 날짜: 2026-11-15
- 관련: ADR-0004, ADR-0007

## 문제

이전 계정의 refresh 응답이 새 계정의 토큰을 덮어쓰거나 세션을 지웠다. 캐시 키를 회원별로 나누어도
인증 토큰 자체가 바뀌면 새 계정 키에 이전 계정 데이터가 저장될 수 있었다.
상담 메시지별 재시도와 요청당 5개 제한은 새로운 메시지를 계속 번역하는 누적 비용을 제한하지 못했다.
정상 종료한 모델의 빈 BODY는 성공으로 저장되어 원문만 보이고 다시 시도하지 않았다.

## 결정

- 메모리 세션 버전과 탭 간 변경 표식을 요청 시작 때 캡처한다. 다른 세션의 응답과 401 재시도는 거절한다.
  로그인·Google 로그인은 프로필 조회까지 검사한 뒤 토큰과 회원을 함께 반영한다.
- 로그인·로그아웃·refresh 모두 같은 Promise 큐와 Web Lock을 쓴다. 진행 중인 쿠키 응답을 중단하지 않고
  완료 후 다음 인증 요청을 보낸다. 늦은 프로필·로그아웃·탈퇴 완료가 새 계정을 변경하거나 이동시키지 않는다.
  다른 탭의 명시적 인증 변경은 메모리 인증과 개인 캐시를 비운다. refresh의 memberId도 현재 회원과 대조한다.
- 공지와 상담 번역은 별도 Redis 누적 예산을 공유한다. 회원은 상담의 학생 또는 공지 최초 작성자로 귀속한다.
  담당자별로 요청을 나누거나 학교·메시지·언어를 바꿔도 책임 회원의 한도를 우회할 수 없다.
- Redis TIME 기준 UTC 일일 회원·학교·전체 횟수와 가중 토큰 예약, 동시 슬롯을 Lua 한 번으로 검사한다.
  회원 동시 1개, 학교 5개, 전체 20개. 작업/호출 임대는 180초이며 공급자 제한 시간은 최대 90초다.
  프로세스 중단 후에는 임대가 만료되고, 이전 작업의 close는 새 소유자의 슬롯을 해제하지 않는다.
- 호출당 최대 입력 65,536바이트(직렬화 여유 포함)와 출력 2,048토큰에 대해 75,776 가중 토큰을 보수적으로 예약한다.
  이 예약은 성공·실패 모두 반환하지 않는다. 정확한 사용량 정산이나 통화 청구가 아니라 지출 상한을 위한 제한이다.
  SDK 자동 재시도는 0이며 공지·상담 번역의 공급자 폴백도 끈다. 캐시 적중과 재시도 대기에는 예약하지 않는다.
- Redis 장애·한도 소진 시 공급자를 호출하지 않는다. 상담은 원문과 translationFailed를, 공지는 실패 언어를 돌려준다.
  예산 거절은 메시지 재시도 횟수를 소비하지 않는다. 빈 제목/본문은 어댑터에서 거절하고, 상담 저장에도 빈 본문을 금지한다.
  기존 빈 캐시는 미생성으로 간주하여 정상 재시도·예산 정책 안에서 복구한다.

## 한계와 운영

Web Locks가 없는 브라우저는 탭 내부 큐와 세션/회원 검사로 보호하지만 탭 사이 쿠키 순서까지 직렬화하지 못한다.
지원 브라우저의 실제 Web Locks·storage 이벤트·Set-Cookie 경합은 두 탭 회귀 테스트로 검증한다.
localStorage 변경 표식에는 토큰·개인정보를 넣지 않는다. 토큰은 계속 메모리에만 저장한다.
번역 예산의 책임 회원은 과금 대상 학교 계약과 구분한다. 실제 금액은 공급자 사용 내역으로 정산해야 한다.
스키마 마이그레이션은 없으며, 이전 앱으로 롤백하면 신규 누적 제한과 빈 캐시 복구는 적용되지 않는다.
