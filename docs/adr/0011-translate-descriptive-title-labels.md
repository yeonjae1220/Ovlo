# ADR-0011: 설명 표지 문구와 원문 식별자 구분

2026-11-17 · Accepted

제목의 식별자·항목 표지를 원문대로 보존하라는 지시가 `[운영 검증 전용]` 같은 설명 문구에도 적용됐다. 이전 실제 출력에는 제목의 한국어 문구가 그대로 남았고, 같은 출력의 독립 의미 검사도 ALLOW/DENY/ALLOW로 달라졌다. 이는 검증 표지를 무조건 허용하거나 거절을 재시도로 덮어서 해결하지 않는다.

번역기는 대괄호 안이나 제목 끝에 있는 설명 문구도 목표 언어로 번역하고 `전용`의 제한 의미를 보존해야 한다. 원문 보존 대상은 실제 문서 코드·고유명 식별자·독립 항목 번호(가/나 등)다. 독립 검증기도 같은 구분을 명시하되, 완전한 번역·사실/숫자/조건/부정/연락처 보존·불확실 시 거절이라는 기준은 그대로 유지한다.

반복 평가 중 독일어 결과의 허용/거절 불일치는 원문 학교를 대학교로 구체화한 번역에서도 발생했다. 별도 사유 진단 4회 모두 이 차이를 지목했다. 번역과 검증에 기관·발행 주체의 구체성 보존을 명시하며 시스템 프롬프트의 대학 문맥에서 원문에 없는 발행 기관을 추론하지 않는다. temperature=0 실험으로도 같은 출력의 판정 변동이 남아 이 설정은 운영에 추가하지 않았다.

코드 게이트는 한국어 원문 제목의 알려진 설명 표지(`운영 검증 전용`, `검증용`, `중요`, `교환학생 안내`)가 외국어 제목에 미번역으로 남으면 거절한다. 공백·대괄호 전각 표기는 정규화하되, 임의의 한국어 고유명이나 식별자를 일괄 차단하지 않는다. 표지 어휘 목록 밖의 의미 판단은 계속 독립 LLM 검증의 책임이다. 단어 일부가 일치하는 고유명은 차단하지 않는다.

회귀 검증은 원래 실패한 제목, 설명 표지와 가/나·문서 코드가 섞인 제목, 미번역 표지, 의미 변조, 금액 바꾸기와 프롬프트 주입을 포함한다. 실제 LLM은 6개 언어에서 3가지 제목을 각각 새로 번역하고 결과마다 의미 검사를 2회 수행한다. 모든 결과가 통과해야 하며 다수결이나 성공할 때까지 자동 재시도하지 않는다. 유한한 반복 검증이 모델의 미래 결정까지 보장하지는 않는다.

모델, 토큰 상한, 비용 예약, 작업 재시도 횟수 및 DB 스키마는 변경하지 않는다.
