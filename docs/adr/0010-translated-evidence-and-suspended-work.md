# ADR-0010: 번역 근거의 동일성과 정지된 번역 작업 복구

2026-11-17 · Accepted

과거 답변을 다시 조회할 때 원문 버전만 검사하면, 검증에서 제외되거나 같은 버전에서 교체된 번역을 여전히 유효한 근거로 표시한다. 새 인용 스냅샷에는 답변 생성에 사용한 번역의 언어·원문 버전·제목·본문에 대한 SHA-256 지문을 저장한다. 대화 조회는 현재 번역의 사용 가능 여부와 지문 일치를 함께 검사한다. 원문 언어 답변에는 기존 원문 버전 검사를 유지한다. 지문이 없는 과거 외국어 답변은 현재 본문으로 소급 인증하지 않고 오래된 근거로 표시한다. 기록된 답변 자체는 보존한다. 기존 JSON 스냅샷은 그대로 읽을 수 있으며 DB 일괄 갱신은 하지 않는다.

국제처 정지는 번역 작업의 영구 취소 사유와 분리한다. V49는 PAUSED 상태를 추가하고, 기존 CANCELLED 중 현재 승인 버전·유효 기간·48시간 수명·시도 한도를 모두 만족하는 작업만 PAUSED로 복구한다. 정지 해제 후 스케줄러 또는 수동 재번역이 재개한다. attempts, created_at, available_at을 초기화하지 않는다. 오래된 버전·보관 공지·만료·시도 소진은 계속 재개하지 않는다. 이주 후 PAUSED 데이터를 처리하려면 새 애플리케이션이 필요하므로 구버전으로의 단순 이미지 롤백은 작업 재개를 보장하지 않는다.

프랑스어 h는 시각과 기간에 모두 쓰인다. dure, durée, pendant, durant 등 명시적인 기간 문맥에 있는 h만 시각 추출에서 제외하고 숫자는 그대로 비교한다. 다른 h 표기와 HH:MM 검사는 유지한다. 코드가 단위 의미를 모두 판별한다고 가정하지 않으며, 숫자가 같은 시간→일 변조 등은 독립 LLM 의미 검증으로 차단한다.

검증: 실제 PostgreSQL·Redis로 지문 변경/검증 제외, 정지·재개, 한도·대기 시간 보존, V48→V49 마이그레이션을 확인한다. 프랑스어 정상/변조 표기 회귀 테스트와 실제 번역·Sonnet 답변/의미 검사·악용 차단 평가를 수행한다. 기존 승인·근거 최종 확정 락, 계정 격리, 비용 예약은 유지한다.
