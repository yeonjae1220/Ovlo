# ADR-0014: 외부 호출 후 권한과 상담 저장 순서

- 상태: Accepted
- 날짜: 2026-11-17

## 문제

요청 진입 시 인증만으로는 LLM 호출 중 담당자 제거·회원 정지·학교 인증 만료·국제처 정지를 반영하지 못했다.
상담 원문과 번역이 권한 회수 뒤 반환됐고, 학생 인증 만료 뒤에도 답변이 저장됐다.
같은 요청에서 다시 조회한 Office/Staff 엔티티도 영속성 컨텍스트의 이전 상태를 반환할 수 있었다.

답변 확정은 office → member, 직접 상담 생성은 member → office 외래 키 순으로 잠갔다.
실제 PostgreSQL에서 동시 실행 시 SQLSTATE 40P01 교착 상태를 재현했다.
직접 상담은 언어 입력이 없어 항상 KO로 저장돼 외국어 학생 메시지를 한국어로 번역하지 않았다.

## 결정

1. 질문 분류·답변 생성·답변 검증 뒤 현재 학생 권한을 검사한다. 답변 확정 트랜잭션과 반환 직전에도 검사한다.
   회원 활성 상태, 국제처 정지 여부, 해당 대학의 활성 인증은 scalar DB 조회로 검사해 이전 엔티티를 신뢰하지 않는다.
   추가 DB 연결을 점유하는 REQUIRES_NEW 권한 트랜잭션은 사용하지 않는다.
2. 상담 번역 전후와 응답 직전 현재 회원 상태·담당자 소속을 검사한다. 권한 예외를 번역 실패로 삼키지 않는다.
   회수된 권한으로 시작한 번역 결과는 캐시에 저장하지 않는다. 이미 지출한 제공자 호출은 취소하거나 무료 처리할 수 없다.
   학생은 회원이 활성 상태라면 기존 동의 상담을 본인 소유 조건으로 읽는다. 학교 인증 만료가 본인 상담 열람까지 막지는 않는다.
3. 답변 확정도 member → office → inquiry/evidence 순서로 잠근다. 외부 LLM 호출 중에는 트랜잭션을 열지 않는다.
   회원/학교의 작업 잠금은 FOR NO KEY UPDATE로 서로 직렬화하되, 키를 바꾸지 않는 작업이 외래 키 참조의 KEY SHARE까지 막지는 않게 한다.
   현재 근거 확인과 office 잠금은 유지하며, 유료 호출을 포함하는 전체 요청 재시도로 교착 상태를 감추지 않는다.
4. 직접 상담 요청에 선택적 `lang`(ko/en/ja/zh/de/fr/vi, 대소문자 허용)을 추가한다. 미지원 값은 400이다.
   문의를 이관하면 저장된 문의 언어를 유지한다. 기존 클라이언트가 생략하면 KO를 사용한다.
   프론트엔드는 현재 UI 언어를 전달한다. 과거 KO 상담을 추측해서 일괄 변경하지 않는다.

## 검증과 한계

실제 보안 필터·PostgreSQL·Redis에서 LLM 단계별 권한 회수, 담당자 제거/국제처·계정 정지,
프랑스어 직접 상담 API·미지원 언어, 답변/직접 상담 경합을 회귀 테스트한다.
교착 상태 테스트는 상담이 회원 잠금을 잡은 뒤 답변의 DB 잠금 대기를 확인하고 진행한다.
정상 답변과 상담 생성이 모두 커밋되는 것을 검사한다. CI에 이 테스트를 포함한다.

실제 LLM 평가는 `OVLO_LIVE_LLM=1`일 때만 실행한다. 정상 Sonnet 답변과 동시 상담,
실제 답변/번역 중 권한 회수, 프랑스어 질문·담당자 답변 번역과 캐시를 검증한다.
권한 검사는 서버의 마지막 검사 시점을 기준으로 한다. 이미 전달된 응답을 회수할 수는 없다.
개별 메시지의 자동 언어 감지·언어 변경은 이번 범위에 포함하지 않는다.

스키마·모델·번역 검사 기준·호출 예산·재시도 상한은 변경하지 않는다.


## 후속 보완: 재번역 응답과 보존된 본인 상담 (2026-11-17)

- 동기 공지 재번역도 요청 시작과 최신 DTO 반환 직전에 현재 회원 활성 상태·국제처 정지·담당자 소속을 scalar DB로 검사한다. 권한 회수 뒤 응답은 403이며 새로 수정된 비공개 본문을 반환하지 않는다. 이미 승인된 학교 소유 번역 작업의 생명주기와 응답 수신 권한은 별개다.
- `GET /api/v1/office/my-consultations`와 `/{id}`는 현재 로그인 회원의 상담만 조회한다. 목록은 기본 20건, 최대 50건이며 학교 인증·현재 담당자 소속과 독립적이다. 타인 상세는 404, 비인증·정지 계정은 차단하고 기존 개인정보 보존기간 마스킹을 유지한다.
- 학생 목록과 직접 상세 링크는 위 경로를 사용한다. 메시지·종료 요청의 학교 ID는 서버에서 받은 본인 상담의 officeId로 정한다. 캐시는 회원별로 격리하며 조회 실패는 빈 목록으로 치환하지 않는다. 새 질문·새 상담 생성은 기존 학교 인증 조건을 유지한다.
- 회귀 검증은 담당자/계정/국제처 권한 회수, 권한 회수 뒤 본문 변경, 인증 만료 후 목록·상세·번역 답변, 타인 소유권, 페이지 상한, 보존기간 만료를 포함한다. 실제 LLM 정상 재번역·호출 중 담당자 해제·학교 인증 없는 기존 상담 번역은 opt-in 평가로 검증한다.
