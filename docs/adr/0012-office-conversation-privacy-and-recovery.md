# ADR-0012: 상담 동의 경계, 개인 본문 삭제와 번역 중단 복구

2026-11-17 · Accepted

담당자 문의 로그·CSV에는 질문, 답변, 피드백 사유를 제공하지 않는다. 상태·언어·시각·처리시간·평가 값·탈락 사유 같은 구조화된 운영 정보만 제공한다. 대시보드의 반복 질문 원문 예시도 제거한다. 이메일 필드가 없다는 사실만으로 자유형 본문을 비식별 데이터라고 보지 않는다. 상담 본문은 학생이 공유에 동의한 상담 경로에서만 확인한다. 기존 동의 기록과 문구는 변경하지 않는다.

학교별 학기 종료일을 저장하지 않으므로 수집 후 1년을 보수적인 상한으로 적용한다. 이는 기존 ‘학기 종료 후 1년까지’보다 짧다. V51은 문의·상담의 최초 수집 시각으로 삭제 기한을 만들며 상태 변경·답변·재로그인으로 연장하지 않는다. 탈퇴 시 즉시 삭제하고, 이미 탈퇴했거나 기한이 지난 데이터는 분당 최대 100명의 배치로 정리한다. 회원 단위 트랜잭션에서 문의 본문·답변·피드백·근거 사본, 상담 질문·답변·전체 대화 사본, 상담방 양측 메시지·번역 캐시를 지운다. 양측 메시지를 지우는 이유는 담당자 답변에도 학생의 개인정보가 인용될 수 있기 때문이다. 통계용 ID·시각·기존 동의 기록은 남긴다. 만료된 사본과 메시지는 배치 실행 전에도 조회 결과에서 숨긴다.

저장과 삭제는 회원 → 문의/상담 → 메시지 순서의 DB 행 잠금으로 조정한다. 삭제 후 도착한 답변, 피드백, 상담 갱신, 메시지 번역 저장은 거부한다. 탈퇴와 동시에 진행하던 외부 LLM 호출 자체를 취소한다고 보장하지는 않지만, 결과가 삭제된 데이터에 재저장되거나 상담 응답에 다시 포함되지 않게 한다. DB 삭제는 과거 백업의 즉시 제거와 다르며, 복원 시 이 삭제 절차를 적용한 후 서비스를 공개해야 한다.

번역 결과를 저장하지 못했을 때 무조건 DONE으로 끝내지 않는다. 학교 정지는 PAUSED로 보존하고, 소유권 상실은 다른 작업자의 상태를 변경하지 않는다. 유료 시도 수·48시간 작업 수명·재시도 대기시간은 유지한다. V51은 현재 버전·승인 상태·48시간 이내·시도 잔여가 있고 번역이 실제로 없는 DONE 작업만 복구한다. 거절/소진 작업은 재개하지 않는다.

검증은 실제 보안 필터와 PostgreSQL·Redis로 동의 전 API/CSV/대시보드 비노출, 탈퇴·만료 정리, 늦은 저장 차단, 최근 데이터 보존, 삭제 멱등성과 호출 중 학교 정지 복구를 확인한다. 실제 LLM 검증은 별도 opt-in으로 수행하며 일반 CI는 합성 출력으로 재현한다.
