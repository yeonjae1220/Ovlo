# 대학 리포트 재생성 (근거 기반) — 파일럿

작성 2026-10-29. 기존 리포트 728개(7개 언어, 5,096행)를 코드로 전수 감사했더니 561개에 심각한 결함이 있었다.
이 문서는 그 감사, 근거 기반 재생성 방식, 파일럿 10개의 운영 반영 절차를 적는다.

## 왜 다시 만드는가

- 옛 리포트는 외부 파이프라인(NAS `data-pipeline/exports/ovlo_import/step5_generate_reports.py`)이
  **qwen3:8b** 로 영어 본문을 쓰고 6개 언어로 번역했다. 프롬프트가 "섹션마다 150단어 이상, 숫자 포함"을 요구해
  근거 없는 사실을 지어냈다.
- 감사 결과(코드 검사, 표본 정밀도 약 9/10):
  - 한국 비자 "D-2"를 독일·미국·대만 등 311개 리포트에 씀
  - 금액 단위 오류("월 150–180 million won", "기숙사 40–60万円/월")
  - 번역하며 숫자가 바뀜(157개 리포트), 현지 통화가 아닌 금액(258개), 프롬프트 흔적 노출(38개)
  - 다른 도시의 식당, 지어낸 과목 코드
- 원천 추적이 끊겼다. 리포트가 가리키던 `exchange_video_reviews` 15,634행은
  `step_backup_youtube.py --delete` 로 지워졌고 백업이 없다. 남은 원천으로 확인되는 리포트는 728개 중 135개뿐이다.
  - 그 원천도 대학 매칭이 틀린 경우가 많다. 바르셀로나에 붙은 영상 25개 중 24개는 다른 대학(두바이 12개)이었고,
    NTU 싱가포르에 붙은 영상 4개는 국립대만대(NTU)였다.
- 평점·추천 비율(`avg_rating`·`recommend_ratio`·`avg_difficulty`)은 LLM 추출값의 평균이라 실제 평가가 아니다.
  그래서 화면과 API에서 뺐다.

## 방식

도구는 `scripts/report_regen/` 에 있다. 작업 데이터는 운영 원문이라 git 에 올리지 않는다.
`OVLO_AUDIT_DIR`(기본 `output/audit-20261029`)에 다음이 있다:
`snapshot/`(운영 READ ONLY 추출), `regen/{packs,country_facts,out,verify}`.

| 단계 | 도구 | 내용 |
|---|---|---|
| 1. 감사 | `audit_stage1.py` | 스냅샷 전 행 검사: 문자 체계, 금액·통화, 언어 간 숫자, 비자와 국가, 프롬프트 흔적, 이름 테이블 |
| 2. 국가 사실표 | (조사 에이전트) | `country_facts/<CC>.json`. 비자·체류허가·수수료·근로 한도·보험·최저임금을 정부·대사관 공식 출처로만 적는다. 확인 못 한 값은 null |
| 3. 원천 묶음 | `build_source_packs.py` | NAS 원천(영상 자막, 크롤링 페이지)을 대학별로 묶는다. 옛 리포트는 "신뢰 불가"로 표시해 맨 끝에 둔다 |
| 4. 생성 | `SPEC.md`, `AGENT_BRIEF.md` | 대학 공식 페이지를 새로 조사하고, 모든 사실을 출처에 연결한다(`claims.jsonl`). 확인 못 한 내용은 쓰지 않는다. 금액은 현지 통화만 |
| 5. 게이트 | `check_report.py`, `gate_regression.py` | 아래 표 참고. 회귀 11개 |
| 6. 독립 검증 | (검증 에이전트) | 생성에 참여하지 않은 에이전트가 표본 주장 60개를 원 출처와 대조하고, 6개 언어 번역을 의미 수준에서 검토 |
| 7. 반영 | `gen_apply_sql.py` | review(ROLLBACK)·apply·rollback SQL 생성 |

게이트(`check_report.py`)가 거부하는 것:
- 7개 언어 누락, 대상 언어로 번역되지 않은 본문(영어 복사·영어 단락), 섹션 수 차이
- 언어 간 숫자 차이(양방향), content 값의 null 여부·목록 길이 차이
- 현지 통화가 아닌 금액. 예외는 `country_facts` 에 같은 통화·같은 값으로 있는 공식 수수료뿐
- 다른 나라의 비자 용어(문맥 필요: "D-2 visa"는 걸리고 "Room D2"는 안 걸림)
- 프롬프트·형식 흔적, zh 번체자, 출처 목록 불일치, 카드 필드 60자 초과
- 주장(claims)으로 뒷받침되지 않는 숫자, `research_log.md` 에 없는 출처 태그

## 운영 반영 순서

1. 이 PR(코드 + V33)을 merge commit 으로 머지하고 배포한다. 운영 이미지 SHA, `flyway_schema_history` 최신 33을 확인한다.
   - V33: 품질 게이트 트리거가 `content.sources`(원문 출처 제목)를 언어 섞임 검사에서 뺀다.
     이게 없으면 파일럿 반영 시 `report_quality_issue` 에 오탐 19건이 생긴다.
   - 상세 조회가 PUBLISHED 만 내보낸다. 이게 없으면 DRAFT 로 내린 1050 이 id 로 계속 열린다.
2. 반영 직전에 현재 행을 다시 추출한다(READ ONLY): 파일럿 번역 70행 + `university_report` 전체.
   ```bash
   python3 -I scripts/report_regen/gen_apply_sql.py <current_dir> <out_dir> \
     --run-id r20261029_pilot --reports 70,1,143,67,266,33,59,299,106,802 --unpublish 1050
   ```
3. 파일 전송: `scp` → `kubectl cp`. **`kubectl exec -i` 의 stdin 으로 큰 파일을 보내면 잘린다**(3.8MB 중 192KB에서
   끊김, 2026-10-29). 로컬·lenovo·파드 세 곳의 sha256 이 같아야 실행한다.
4. `review.sql`(끝이 ROLLBACK)을 실행해 가드·사후 검증·건수를 본다. 그다음 `apply.sql` 을 실행한다.
   - 가드: 대상 행이 추출 이후 바뀌었으면 전체를 중단한다.
   - 백업: 대상 행 전부를 `report_regen_backup_<run>_tr/_ur` 에 before/after 로 남긴다. 기존 백업이 있으면 실패한다.
   - 사후 검증: 저장된 값이 의도한 값과 다르면 전체를 중단한다.
5. 다시 추출해 대조한다. 공개 API `/api/v1/university-reports/70?lang=de` 와 리포트 상세 화면을 확인한다.
6. 복구: `rollback.sql`. after 행 이후 누가 고쳤으면 중단한다. `updated_at` 은 트리거 때문에 복구 시각이 된다.

## 결정 (2026-10-29)

- 공식 가격: 대학·정부 공식 페이지가 외화로만 적은 가격은 그 통화·금액 그대로 쓴다. 같은 항목에 현지 통화 공식 값이 있으면 현지 값을 쓴다.
  게이트는 `O` 출처 claim 의 인용문에 들어 있는 (통화, 금액)만 허용한다. 영상·기타 출처의 외화는 여전히 거부한다.
- 교환 경로가 없는 대학(스탠퍼드 등)도 목록에 남긴다. 실제로 갈 수 있는 경로(방문학생·여름학기 등)를 안내한다.
- 생성 리포트는 모든 언어에서 존댓말·경어체다: ko 존댓말, ja です・ます, de "Sie", fr "vous". 사용자가 올리는 글은 예외다.
  게이트가 ko 평서 종결(-다)·ja 보통체·de du·fr tu 를 잡는다.
- 나머지 717개도 재생성한다. 국가 사실표는 `COUNTRY_BRIEF.md` 로 만들고 다른 에이전트가 공식 출처로 다시 확인한다.
  외교부 여행경보 단계와 여행금지 여부(`travel_advisory`)를 넣는다.
