## 실행 순서와 경계

1. 출처 표시·자료 검토 도구를 보완하고 단위·브라우저 검사를 실행한다.
2. 실제 PostgreSQL·Redis·애플리케이션을 사용한 합성 사용자 여정을 검증한다.
3. 운영 백업의 도착·무결성·격리 복원과 과거 탈퇴 정리 리허설을 기록한다.
4. 허용된 집계 지표와 합성 AI 평가를 점검하고, 수정본을 CI·배포·운영 검증한다.

- 문의 이메일·외부 AI 업체/보관 정책과 이에 의존하는 개인정보 문서 확정·동의 버전 변경은 사용자 요청으로 준비 상태를 유지한다.
- 원래 계획은 HEIC 지원 확정 전 미지원을 정확히 안내하는 것을 허용한다. 신규 HEIC/WebP 디코더, 영상 변환, 저장량 상품 정책은 이 후속 작업의 완료 조건이 아니다.
- 724개 대학의 모든 사실을 전수 검증했다고 표시하지 않는다. 자료별 검토 상태·근거·확인일을 남기고 변동이 큰 항목은 별도 검토 대상으로 관리한다.
- 운영 사용자 계정을 검증용으로 변경하지 않는다. 실제 파괴적 정리와 장애 주입은 구체적인 대상·복구 가능성을 확인한 뒤 별도 판단한다.
- 알림 설정 확인과 실제 수신은 구분한다. 사용자에게 허용받지 않은 메시지를 외부 수신자에게 보내지 않는다.
- 2026-11-24 사용자 결정: 복원 사본에서 23개 계정 익명화와 활성 5개 계정 불변을 검증했지만 **운영의 과거 탈퇴 계정 정리는 보류**한다. 배포에 일괄 정리 활성화 설정을 넣지 않는다.

## 이번 작업의 증거

### 완료한 후속 작업

- 리포트 출처·기준일·180일 초과·누락 안내를 9개 UI 언어로 추가했다. 출처를 접을 수 있는 링크 목록으로
  제공하고, 기숙사 정보가 없는 상태를 ‘없음’과 구분한다. 잘못된 URL·인증 정보가 포함된 URL은 링크로 만들지 않는다.
- 읽기 전용 검토 목록 생성기와 [공식 자료 표본 대조](report-evidence-review.md)를 추가했다.
  현재 724개 리포트·5,068개 번역의 메타데이터 검사를 통과했다. 개별 사실의 전수 검증 완료를 뜻하지 않는다.
- 실제 브라우저에서 발견한 읽음 표시 최초 저장 경합을 방 행 잠금과 단조 증가하는 시각 저장으로 수정했다.
  운영 PostgreSQL과 로컬 H2에서 같은 동시성 규칙을 적용한다.
  동시 요청 8개가 모두 정상 처리되고 읽은 시각이 과거로 되돌아가지 않는 것을 확인했다.
- 실제 HTTP·보안 필터·PostgreSQL·Redis·STOMP를 연결한 `ServiceJourneyIntegrationTest`를 추가했다.
  가입→로그인/갱신→글/댓글→학교/개인 일정→학교 인증/공지/문의/동의한 상담 이관→사진 업로드/중고거래/문의→
  탈퇴/재가입까지 실행한다. 학교 배정과 검증된 공지는 격리된 관리자 fixture로 준비하며 외부 AI는 fake adapter다.
- 같은 실제 백엔드와 Next.js를 연결해 PC·모바일 **36개 브라우저 확인 항목**을 통과했다.
  9개 언어의 출처·키보드 조작, 오래됨/누락 상태, 로그인 복귀, 새로고침 후 인증, 글 저장,
  실제 소켓 단절 후 재구독·채팅 이력 복원을 포함한다. API 응답을 모의 처리하지 않았다.
- 집계 전송 allowlist에 문의 지연·LLM 호출/토큰/지연을 추가했다. 모델·목적·결과는 고정된 값만 허용한다.
  실제 OTLP 본문에서 임의 태그·본문·식별자·exemplar가 배제되는지 검사했다.
- 별도의 제한된 유료 AI 평가: 합성 질문 4개가 모두 기대 결과와 일치했다(정상 답변 2, 근거 없음 1, 범위 밖 1).
  실제 호출 9회, 입력 8,082·출력 314토큰, 재시도 없음. 응답 시간은 약 1.65–8.38초였다.
  이 표본 결과를 전체 정확도나 청구 금액으로 일반화하지 않는다. 학생 질문은 사용하지 않았다.
- 배포 실패 안내의 이미지 단독 롤백 명령을 제거했다. 구 이미지의 인증된 health endpoint와 새 공개 probe가
  맞지 않으므로 호환되는 Deployment 설정까지 함께 복원하도록 안내한다.

  기존 수신자에 대한 실제 전송 결과는 최종 운영 점검에서 별도로 관측한다.
