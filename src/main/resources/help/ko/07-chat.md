# 채팅

채팅 목록
- 상단 메뉴(모바일은 아래 메뉴)의 "채팅"(/chat)에서 내 채팅방을 봅니다.
- 읽지 않은 메시지 수가 채팅방마다 표시되고, 100개 이상이면 99+로 보입니다.

1:1 메시지(DM) 시작하기
- 채팅 화면에서 상대방 닉네임을 검색하고 "DM 시작 →"을 누릅니다.
- 그 사람과 이미 DM이 있으면 기존 대화방이 열립니다.

채팅방 만들기
- "+ 채팅방 만들기"를 누르고 종류(DM 또는 그룹), 방 이름, 초대할 회원을 고릅니다.
- 지금은 채팅방을 만들 때 한 명만 고를 수 있고, 나중에 사람을 더 초대하는 기능은 없습니다.

메시지 보내기와 읽음 표시
- 화면에 "온라인"으로 연결된 뒤에 메시지를 보낼 수 있습니다. 연결이 끊기면 입력창이 잠깁니다.
- 내가 보낸 메시지에 ✓ 하나는 전송됨, ✓✓는 다른 참여자가 모두 읽었다는 뜻입니다.
- 보낸 메시지는 수정하거나 삭제할 수 없습니다.
- 나를 차단했거나 내가 차단한 사람과는 DM을 시작하거나 보낼 수 없습니다.
