# 회원 탈퇴

탈퇴하는 방법
- 내 프로필 화면 아래쪽, 로그아웃 옆의 "회원 탈퇴" 버튼을 누릅니다.
- "정말 탈퇴하시겠습니까? 이 작업은 되돌릴 수 없습니다." 확인 창에서 확인을 누르면 탈퇴됩니다.
- Apple로 가입한 계정은 탈퇴 전에 Apple 인증을 한 번 더 거치고, Apple ID 연결도 해제됩니다.
- Android 앱에서는 Apple로 가입한 계정을 탈퇴할 수 없습니다. 웹사이트나 iOS 앱에서 탈퇴해 주세요.

탈퇴하면 바로 일어나는 일
- 닉네임, 이름, 이메일, 비밀번호, 고향, 대학교, 전공, 프로필 사진, 자기소개 같은 계정 정보가 지워지거나 알아볼 수 없게 바뀝니다.
- 작성한 게시글, 댓글, 채팅 메시지는 다른 사람에게 보이지 않게 숨겨집니다.
- 팔로우·팔로워 관계가 사라집니다.
- 학생 인증 정보와 개인 캘린더 일정이 삭제됩니다.
- 올린 사진 등 파일은 삭제 대기열에 들어가 곧 삭제됩니다.
- 학교 국제처에 남긴 질문과 상담 내용도 삭제됩니다.

탈퇴한 계정은 되살릴 수 없습니다. 다시 이용하려면 새로 가입해야 합니다.
