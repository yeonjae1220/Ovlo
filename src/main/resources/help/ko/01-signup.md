# 회원가입

Ovlo는 이메일, Google, Apple 세 가지 방법으로 가입할 수 있습니다.

이메일로 가입하기
- 로그인 화면에서 회원가입(/register)으로 들어가 "일반 회원 가입"을 고릅니다.
- 1단계 계정 정보: 닉네임, 이메일, 비밀번호를 입력합니다.
- 2단계 개인 정보: 이름과 고향을 입력합니다.
- 3단계 학업 정보: 대학교(검색), 전공, 화면 언어, 학위(학사·석사·박사), 학년(1~6)을 입력합니다.
- 가입을 마치면 로그인 화면으로 이동합니다. 자동으로 로그인되지 않으니 방금 만든 이메일과 비밀번호로 로그인해 주세요.

닉네임 규칙
- 2~30자이며 영문, 숫자, 마침표(.), 밑줄(_)만 쓸 수 있습니다.
- 입력하는 동안 이미 쓰이는 닉네임인지 확인합니다.

비밀번호 규칙
- 8~100자입니다.
- 영문 대문자, 영문 소문자, 숫자, 특수문자를 각각 하나 이상 넣어야 합니다.
- 특수문자는 @ $ ! % * ? & _ # ^ ( ) - 만 쓸 수 있습니다.

Google·Apple로 가입하기
- 로그인 화면의 Google 또는 Apple 버튼을 누릅니다.
- 처음 가입하면 프로필 마무리 화면(/onboarding)으로 이동해 고향, 대학교, 전공, 학위, 학년을 입력합니다.
- Apple 버튼은 Android 앱에는 표시되지 않습니다.
- Apple로 가입할 때 이메일을 공유하지 않으면 가입할 수 없습니다.

학교 담당자 가입
- 회원가입 화면의 "학교 담당자 가입"은 대학 직원용입니다. 운영자 검토를 거친 뒤에 담당자 기능을 쓸 수 있습니다.

가입하면 이용약관(/terms)과 개인정보처리방침(/privacy)에 동의한 것으로 봅니다.
