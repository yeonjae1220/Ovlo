# 신고와 차단

신고하기
- 게시글, 댓글, 채팅 메시지, 회원을 신고할 수 있습니다. 각 화면의 신고 버튼을 누릅니다.
- 신고 사유는 스팸·사기, 괴롭힘·따돌림, 혐오 표현·차별, 음란·성적인 콘텐츠, 폭력·위협, 불법 행위, 개인정보 노출, 기타 중에서 고릅니다.
- "기타"를 고르면 내용을 적어야 합니다. 설명은 1,000자까지입니다.
- 내 콘텐츠는 신고할 수 없습니다.
- 신고한 사람이 누구인지는 상대에게 알려지지 않습니다.
- 운영자가 신고를 검토해 기각하거나, 콘텐츠를 삭제하거나, 작성자를 정지합니다. 정지된 회원은 로그인할 수 없습니다.

차단하기
- 다른 회원의 프로필에서 "차단"을 누릅니다. 1:1 채팅방에서도 상대를 차단할 수 있습니다.
- 차단하면 서로의 게시글과 댓글이 보이지 않습니다.
- 서로 DM을 시작하거나 보낼 수 없습니다.
- 서로의 팔로우 관계가 사라집니다.
- 중고거래에서 상대의 판매 글이 보이지 않고 거래 채팅도 할 수 없습니다.
- 자기 자신이나 탈퇴한 회원은 차단할 수 없습니다.

차단 풀기
- 내 프로필의 "차단한 회원 보기"(/blocks)에서 차단을 해제합니다.
- 내가 차단을 풀어도 상대가 나를 차단한 것은 풀리지 않습니다.
