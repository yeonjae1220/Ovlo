# 로그인과 로그아웃

로그인
- 로그인 화면(/login)에서 가입한 방법과 같은 방법으로 로그인합니다.
- 이메일·비밀번호로 가입한 이메일로는 Google 로그인을 할 수 없습니다. "이미 이메일/비밀번호로 가입된 계정입니다" 안내가 나오면 이메일 로그인을 이용해 주세요.
- 이미 다른 방법으로 가입한 이메일로는 Apple 로그인을 할 수 없습니다.
- 앱에서 Google 로그인을 누르면 휴대폰의 기본 브라우저가 열립니다.
- 로그인 시도는 10분에 10번까지입니다. 너무 많이 시도했다면 잠시 뒤 다시 시도해 주세요.
- 정지되었거나 탈퇴한 계정으로는 로그인할 수 없습니다.

로그인 유지
- 한 번 로그인하면 최대 30일 동안 로그인 상태가 유지됩니다.

로그아웃
- 내 프로필 화면 아래쪽의 "로그아웃" 버튼을 누릅니다. 로그아웃하면 로그인 화면으로 이동합니다.
- 내 프로필은 상단 메뉴의 "프로필"(모바일은 "더보기" → "프로필")에서 열 수 있습니다.

비밀번호를 잊었을 때
- 지금은 앱 안에 비밀번호 찾기 기능이 없습니다. 도움이 필요하면 support@mungji.com 으로 문의해 주세요.
