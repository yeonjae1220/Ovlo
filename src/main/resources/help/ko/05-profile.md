# 프로필과 화면 설정

프로필 편집
- 내 프로필 화면에서 "프로필 편집"을 누르면 닉네임과 자기소개를 바꿀 수 있습니다.
- 닉네임은 2~30자이며 영문, 숫자, 마침표(.), 밑줄(_)만 쓸 수 있습니다. 자기소개는 500자까지입니다.
- 이름, 이메일, 대학교, 전공은 화면에서 바꿀 수 없습니다.

프로필 사진
- 내 프로필 화면에서 사진(아바타)을 누르면 바꿀 수 있습니다.
- JPEG와 PNG만 올릴 수 있고, 한 장에 최대 20MB입니다.
- HEIC나 WebP 사진은 지원하지 않으니 JPEG나 PNG로 바꿔서 올려 주세요.

다른 사람에게 보이는 정보
- 다른 회원이 내 프로필을 볼 때 이메일과 생일은 보이지 않습니다.

언어와 테마
- 화면 언어는 상단의 언어 선택 버튼이나 내 프로필에서 바꿀 수 있고, 바로 적용됩니다.
- 고를 수 있는 언어는 English, 한국어, 日本語, 中文, Русский입니다.
- 밝은 화면·어두운 화면(테마)을 바꿀 수 있고, 이 설정은 지금 쓰는 기기에 저장됩니다.

팔로우
- 다른 회원의 프로필에서 "팔로우"를 누르면 팔로우하고, "언팔로우"로 취소합니다.
- 프로필에서 팔로워·팔로잉 수를 볼 수 있습니다. 자기 자신은 팔로우할 수 없습니다.
